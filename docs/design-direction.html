PLATE 01
The evidence — proof, not adjectives

Every defect is measured, photographed, and checked against the standard — pass or fail. That single annotated finding is what the whole site is built from: it appears in the report, in a zoomable viewer, and here.

The photography is shot like evidence, not like a brochure: sharp macro, a low raking light to reveal the defect, a scale in the frame, the instrument’s reading legible, and a calibration strip proving the image is true to tone. The measurement mark‑up is the design.

PLATE 02
Colour — paper, ink & one measured signal

Warm‑neutral paper, near‑black ink, and a single red — used only where something has been measured and found out of tolerance. It leaves buttons and links alone; those stay quiet ink and hairline. When you see red, it means a number, and a failure. Conformance is stated in words, never colour alone.

PLATE 05
A technical library

A growing library of the technical facts this work turns on — defect types, tolerances, standards and test methods. We build it from real casework; our own reports draw on it; and it’s useful enough that the industry uses it too. Each entry is dated, reviewed, and tied to the standard it explains, so it stays current.

DEFECTS
Defect index
One clear entry per failure — lippage, debonding, tenting, efflorescence, movement‑joint failure — how to spot it, and why it happens.
NUMBERS
Tolerances
The tables people actually look up — permissible lippage, surface regularity, deflection, moisture limits — with the standard each comes from.
STANDARDS
Standards, explained

METHODS
Test methods
How each check is done — adhesion, tap survey, moisture, flatness, slip resistance — with the instrument and the standard.

Built from work already being done — so it grows as the practice does.

PLATE 07
Motion — quiet and exact

it’s wrong.

Content settles into place with a short, mechanical fade‑and‑rise as you scroll — the movement you’ve been reading through. Numbers settle to rest like a needle, not a spinning odometer. PLATE 08
Decisions to lock before Phase 1

Five answers close every ambiguity.

  1. Name — a coined, ownable mark for the firm (recommended), cleared for trademark before launch, rather than a founder’s surname.
  2. Signal colour — instrument red (recommended), used only for a measured, out‑of‑tolerance finding.
  3. Reports shown as a real, browsable product, with work labelled by provenance.
  4. A one‑day photography shoot (defect plates + a portrait) so launch runs on real evidence, not stock.
  5. Serif confirmed in, for reports and articles.
